> ไฟล์นี้แทนสเปกหน้าจอของ `README_v3.md` สำหรับหน้า DRIVE, FOCUS, TRIP, SET, แถบแท็บ และ toast

## เป้าหมายของ v4

1. **ให้ความรู้สึกเป็นเกจรถยนต์:** shift light, ตัวเลขบนหน้าปัด, เครื่องหมาย peak, ลูกศรแนวโน้ม
2. **โต้ตอบได้มากขึ้น:** ปัดเปลี่ยนหน้า, แตะค่าเพื่อดูละเอียด, กดค้างเพื่อล้างค่า, รายการตั้งค่าที่ลากเลื่อนได้
3. **ใช้ข้อมูลที่มีอยู่แล้วให้คุ้ม:** ไม่เพิ่ม PID ใหม่ ทุกอย่าง (สถิติ, กราฟ, trip, 0–100) คำนวณจาก 8 ค่าที่อ่านอยู่แล้ว
4. **ไม่แตะ logic OBD / Bluetooth** เปลี่ยนแค่ชั้นแสดงผลและการจัดการสัมผัส

## กฎที่ยังใช้จาก v3

- ฟอนต์ขั้นต่ำ 10px, พื้นสีเดียว `fillScreen(theme.bg)`, ทุกสีมาจาก struct ธีม

## 01 DRIVE

### Shift light (y 26, สูง 5)

- 15 ช่อง กว้าง (308 − 2·14)/15 ≈ 18.7 ห่าง 2 เริ่ม x 6, มุมโค้ง 1
- ติดจาก `shift − 1500` ถึง `shift` รอบ (ค่า `shift` ตั้งได้ในหน้า SET ค่าเริ่มต้น 6,000)

## 03 TRIP + จับเวลา 0–100 km/h

### สถิติการเดินทาง (การ์ด 93×46 ตาราง 2×3 เริ่ม (6, 28) ห่าง 4)

| การ์ด | การคำนวณ |
|---|---|
| TIME | เวลาที่มีค่าจากรถ (เครื่องติด) `m:ss` หรือ `h:mm:ss` |
| DIST km | Σ speed × Δt (ทศนิยม 1) |
| AVG km/h | DIST / MOVING (แสดง `--` จนกว่า MOVING > 5 วินาที) |
| MAX km/h | ความเร็วสูงสุด |
| MAX RPM | รอบสูงสุด |
| MOVING | เวลาที่ความเร็ว > 1 km/h |

ป้าย 10px `muted`, ค่า 20px bold baseline y+38, หน่วย 10px `muted` ชิดขวา
`RESET TRIP · HOLD 2s` (6, 180) 190×24 แบบปุ่มอันตราย (ขอบ `bad`)

> ระยะทางจากการรวมความเร็วจะคลาดเคลื่อนตามอัตราการอ่านค่า (ความเร็วถูกอ่านประมาณทุก 0.5–1 วินาที) ใช้ดูคร่าวๆ ไม่ใช่ odometer

### การ์ด 0–100 (200, 28) 114×176

| สถานะ | ป้าย | ตัวเลขใหญ่ (30px bold) |
|---|---|---|
| OFF | `OFF` `muted` | `--.-` |
| ARMED (รถยังไม่หยุด) | `STOP FIRST` `warn` | `--.-` |
| READY (ความเร็ว 0) | `READY` `ok` พื้นกะพริบ `accentSoft` 1 Hz | `0.0` |
| RUN (ความเร็ว > 0) | `GO` `accent` | เวลาที่เดิน ทศนิยม 1 สี `accent` |
| DONE (ถึง 100) | `RESULT` `ok` | ผลเวลา |

- แถบความคืบหน้า 4px ตามความเร็ว 0–100 ที่ y+100, `BEST` แสดงเวลาดีสุดของ session
- ปุ่ม `ARM` (accent) / `CANCEL` 98×32 ที่ y+136
- ถึง 100 แล้ว: เสียง confirm + toast `0–100 IN 8.8 s` (`NEW BEST` หรือ `BEST x.x`)
- **ความแม่นยำ:** เริ่มจับเมื่อความเร็วที่อ่านได้ > 0 และหยุดเมื่อ ≥ 100 ผลคลาดได้ประมาณช่วงการอ่านความเร็ว
  ถ้าจะให้แม่นขึ้น ระหว่าง RUN ให้ถาม `010D` บ่อยขึ้น (เช่นสลับ RPM / SPEED เท่านั้น) — เป็นการเปลี่ยน `POLL_SEQUENCE` ชั่วคราว ต้องตกลงกันก่อนลงมือ

## SCAN

โครงเดียวกับ v3 แต่ปรับให้เข้ากับ v4: หัว `SELECT ADAPTER` + นับถอยหลัง / จำนวนที่เจอ + แถบความคืบหน้า 2px ใต้หัว, แถวสูง 32 ห่าง 4, ป้าย `OBD` / `SAVED` พื้น `accent`
แถบล่าง: `BACK` · `MANUAL` · `RESCAN` (accent, กดไม่ได้และเป็นสีปกติระหว่างค้นหา)

## Toast (แถบเตือนไม่บังจอ)

- (6, 32) 308×23 พื้น `surf` ขอบ 1px และแถบซ้าย 4px สีตามชนิด, ข้อความ 11px bold สีตามชนิด, รายละเอียดชิดขวา 10px `muted`
- ขึ้นทันที (prototype มีการเลื่อนลง/จาง แต่จอ TFT ไม่มี framebuffer จึงไม่ทำ) อยู่ 4 วินาที แตะเพื่อปิด, เสียงสองปี๊บเฉพาะแบต/น้ำมันต่ำ
- มีได้ครั้งละ 1 อัน อันใหม่แทนที่อันเก่า

| เหตุการณ์ | ชนิด | ข้อความ |
|---|---|---|
| แบตเตอรี่ลดต่ำกว่า 12.2 V | warn | `BATTERY LOW` · `12.1 V` |
| น้ำมันต่ำกว่า 10 % | warn | `FUEL LOW` · `8 %` |
| สัญญาณ OBD หลุด | bad | `OBD LINK LOST` · `RETRY 4 s` |
| ลบ DTC สำเร็จ | ok | `CODES CLEARED` · `MIL OFF` |
| จบ 0–100 | ok | `0–100 IN 8.8 s` · `NEW BEST` |

เตือนเฉพาะตอนข้ามเกณฑ์ (ค่ากลับขึ้นมาเหนือเกณฑ์ก่อนจึงเตือนได้อีก) น้ำหล่อเย็นร้อนเกินยังใช้หน้า ALERT เต็มจอแบบ v3

## การปัด (swipe)

- ใช้ได้ในหน้า DRIVE, FOCUS, TRIP, FAULT (วนรอบ) ไม่ใช้ในหน้า SET / SCAN / คีย์บอร์ด
- เงื่อนไข: เริ่มแตะในพื้นที่เนื้อหา (y 24–207), ระยะแนวนอน > 50px, แนวนอน > 1.5 × แนวตั้ง, ใช้เวลา < 700 ms
- ปัดแล้วเล่นเสียงติ๊ก ไม่นับเป็นการแตะปุ่มที่นิ้วเริ่มกด

ขนาดเดิมของ v3 ครอบคลุมทั้งหมด: 10, 11, 12, 14, 18, 20, 24, 30, 50 ไม่ต้องสร้างเพิ่ม
ตัวอักษรใหม่ที่ต้องมีในฟอนต์: `–` (en dash ใน `0–100`), `−` (minus ใน `−60 s` และปุ่ม), `•` (PIN)

## หมายเหตุสำหรับเฟิร์มแวร์

- **ไม่แก้ OBD task** ค่าทั้งหมดในหน้าใหม่คำนวณใน `loop()` จาก `getView()` ทุก 200 ms (สถิติ, trip) และทุก 1 วินาที (ประวัติกราฟ)
- **Swipe และลากเลื่อน** ต้องเพิ่มใน `handleTouchEvents()`: เก็บจุดเริ่ม (`touch.x/y` ตอน pressEdge) และตรวจระยะตอน releaseEdge / ระหว่าง `touch.down`
  จอ resistive ให้พิกัดสั่นเล็กน้อย ใช้ค่าที่กรอง EMA แล้ว (`touch.x/y`) และเกณฑ์ 8–12px ตามที่ระบุ
- **Shift light กะพริบ 4 Hz** ต้องวาดใหม่ทุก 125 ms แต่วาดแค่แถบสูง 5px จึงเร็ว (ทำนอกรอบ 200 ms ได้)
- **วงโค้งมาตรวัด** ใช้วิธีเดิมของ v3 (วาดเฉพาะช่วงที่เปลี่ยน) peak marker วาดหลังวงโค้ง และต้องลบขีดเก่าเมื่อ peak เปลี่ยน
- **รายการ SET** วาดแถวที่มองเห็นใหม่ทั้งพื้นที่ทุกครั้งที่ offset เปลี่ยน (ลดการวาดด้วยการปัด offset ทีละ 2px) ต้อง clip ไม่ให้ทับแถบสถานะ / แท็บ
- กราฟ FOCUS วาดใหม่ทั้งการ์ดทุก 1 วินาที (308×52 เร็วพอ)

## การตัดสินใจ (ก่อนลงเฟิร์มแวร์)

1. **DRIVE ใช้การ์ดคงที่ 4 ใบ** (COOL, BATT, FUEL, THR) INTAKE / LOAD ดูในหน้า FOCUS ยังไม่ทำให้เลือกการ์ดเองได้
2. **ไม่เพิ่มความถี่การอ่านความเร็ว** ระหว่างจับ 0–100 (ไม่แก้ OBD task) ยอมรับความคลาดเคลื่อนประมาณ 0.5–1 วินาที
3. **เวลา 0–100 ดีสุดจำเฉพาะรอบที่เปิดเครื่อง** ไม่เก็บใน NVS (ไม่มี key `best0100`)
4. **หน้าเว็บยังไม่เปลี่ยน** ในรอบนี้
